Ícone do Framux (fonte do "F" e do nome: Gugi, licença SIL Open Font License)

framux.svg            -> ícone vetorial (principal no Linux)
png/framux-N.png      -> ícone em PNG N×N px
framux.ico            -> .ico multi-tamanho (caso precise)
framux-wordmark.svg   -> nome "Framux" (texto branco, para fundo escuro)
framux-wordmark.png   -> o mesmo em PNG transparente

Instalação típica no Linux (por usuário):
  for s in 16 24 32 48 64 128 256 512; do
    install -Dm644 png/framux-$s.png ~/.local/share/icons/hicolor/${s}x${s}/apps/framux.png
  done
  install -Dm644 framux.svg ~/.local/share/icons/hicolor/scalable/apps/framux.svg
  gtk-update-icon-cache ~/.local/share/icons/hicolor 2>/dev/null

No arquivo framux.desktop:
  Icon=framux
